# Lista de Tarefas

Aplicação de lista de tarefas desenvolvida com Next.js, React e CSS.

## Funcionalidades
- Adicionar tarefas por formulário
- Marcar tarefas como concluídas ou pendentes
- Excluir tarefas
- Filtrar todas, pendentes e concluídas
- Exibir totais e contadores
- Persistir tarefas no navegador com localStorage

## Executar localmente
1. Instale o Node.js LTS.
2. No terminal, dentro da pasta do projeto, execute `npm install`.
3. Execute `npm run dev`.
4. Abra http://localhost:3000.

## Publicar
Envie o projeto para um repositório GitHub e importe esse repositório na Vercel. A Vercel detecta Next.js automaticamente.
